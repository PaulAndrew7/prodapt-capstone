# 1 Purpose
This policy sets how changes are made to Kestrel Mutual production systems.

# 2 Normal changes

## 2.1 Change record
Every change to a production system needs an approved change record before it is made.

## 2.2 Approval
Normal changes are approved by the Change Advisory Board at its weekly meeting.

## 2.3 Change window
Normal changes are made only between 19:00 and 07:00 on weekdays, or at weekends.

## 2.4 Rollback plan
Each change record must include a tested rollback plan.

## 2.5 Peer review
Code changes must be reviewed by an engineer other than the author before release.

# 3 Emergency changes

## 3.1 Emergency change exception
An emergency change needed to restore a service may be made without Change Advisory Board approval, instead of following clause 2.2, if the on-call engineering manager approves it. The Change Advisory Board reviews it within two working days.

# 4 Change freeze

## 4.1 Year-end freeze
No normal changes are made to customer-facing systems between 15 December and 5 January.
